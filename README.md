# Wallet

**Wallet** is a simple and secure Android app designed to help users manage their finances, store payment methods, and keep track of transactions. Built with **XML** layouts and **Java/Kotlin** for Android development, this app ensures a smooth user experience and easy navigation.

## Features

- **Transaction History**: Track your spending by viewing past transactions.
- **Budget Management**: Set a budget for the month and keep track of spending.
- **Dark/Light Mode Support**: The app adjusts to the system theme automatically.
- **Customizable Categories**: Create categories for your expenses (e.g., groceries, bills, entertainment).

## Tech Stack

- **Kotlin**: Programming languages used for Android development.
- **XML**: Layouts and UI design for the app.
- **SQLite**: Local database used for storing wallet data and transaction records.
- **SharedPreferences**: For storing user settings and preferences (e.g., authentication method).
